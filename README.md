# Course Predictor ML

An ML-powered tool that predicts course suitability and admission chances for graduate programs. Enter your academic profile and get instant recommendations powered by ensemble machine learning and semantic similarity.

---

## 🚀 How to Run

**1. Clone the repository and navigate into the folder**
```bash
git clone https://github.com/vinay0304/Course-Predictor-ML.git
cd Course-Predictor-ML
```

**2. Install dependencies**
```bash
pip install -r req1.txt
pip install sentence-transformers streamlit==1.31.1
```

**3. Run the app**
```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser — that's it!
